Repositori ini berisi kode sumber dan dokumentasi lengkap untuk **Proyek Akhir Sistem Basis Data**. Proyek ini merancang dan mengimplementasikan sistem basis data relasional berbasis SQL/Oracle untuk mengoptimalkan manajemen data akademik di SDN 1 Kota Malang secara terpusat dan *real-time*.

---

## 🏛️ Informasi Akademik
* **Mata Kuliah:** Sistem Basis Data
* **Institusi:** Fakultas Ilmu Komputer, Universitas Brawijaya (FILKOM UB)
* **Penulis:** Rezky Auliasarie (Teknik Komputer)

---

## 💡 Latar Belakang & Tujuan
Pengelolaan data akademik sekolah sering kali menghadapi kendala efisiensi jika masih dilakukan secara terpisah. Proyek ini bertujuan untuk membangun arsitektur basis data relasional yang andal guna mengelola berbagai entitas penting sekolah seperti **siswa, guru, kelas, absensi (kehadiran), hingga nilai** secara terpusat, aman, dan terstruktur untuk mendukung operasional harian SDN 1 Kota Malang.
